# 文档编写规则

## 1. 文件命名规范

### 1.1 基本规则
- 使用小写字母
- 单词之间使用连字符 `-` 分隔
- 避免使用特殊字符和空格
- 保持文件名简洁明了

### 1.2 示例
```
✅ 正确：javascript-promise-tutorial.md
✅ 正确：react-hooks-best-practices.md
❌ 错误：JavaScript Promise Tutorial.md
❌ 错误：react_hooks_best_practices.md
```

## 2. 文件结构规范

### 2.1 前置元数据
每个文档文件开头必须包含以下元数据：

```yaml
---
title: 文档标题
date: YYYY-MM-DD
tags: [标签1, 标签2, 标签3]
category: 分类
description: 简要描述
---
```

### 2.2 文档结构
```markdown
# 一级标题（文档标题）

## 二级标题（主要章节）

### 三级标题（子章节）

#### 四级标题（如果需要）
```

## 3. 内容编写规范

### 3.1 标题规范
- 一级标题只能有一个，作为文档标题
- 标题层级不能跳级（不能从一级直接到三级）
- 标题要简洁明了，准确描述内容
- 避免使用标点符号结尾

### 3.2 段落规范
- 每段文字控制在3-5行内
- 段落之间空一行
- 避免过长的句子（建议不超过25个字）
- 使用简洁明了的语言

### 3.3 列表规范
- 无序列表使用 `-` 或 `*`
- 有序列表使用数字加英文句点
- 列表项之间保持平行结构
- 嵌套列表缩进2个空格

```markdown
- 一级列表项
  - 二级列表项
  - 二级列表项
- 一级列表项

1. 第一步
2. 第二步
   1. 子步骤
   2. 子步骤
3. 第三步
```

## 4. 代码规范

### 4.1 代码块格式
- 使用三个反引号包围代码块
- 指定正确的编程语言
- 代码要有适当的缩进
- 避免过长的代码行（建议不超过80字符）

```javascript
// ✅ 正确的代码块
function example() {
  console.log('Hello World');
}

// ❌ 错误的代码块
function example() {
console.log('Hello World');
}
```

### 4.2 行内代码
- 使用单个反引号包围行内代码
- 用于变量名、函数名、命令等
- 避免过长的行内代码

例如：使用 `console.log()` 函数来输出调试信息。

## 5. 链接和图片规范

### 5.1 链接规范
- 使用描述性的链接文本
- 外部链接考虑添加提示
- 保持链接文本简洁

```markdown
[React 官方文档](https://react.dev/)
[查看详细教程](./tutorial.md)
```

### 5.2 图片规范
- 使用描述性的alt文本
- 图片文件放在 `assets/` 目录
- 保持图片尺寸适中
- 考虑添加图片说明

```markdown
![代码调试示例](../assets/debug-example.png)
*图1：Chrome DevTools调试界面*
```

## 6. 技术文档特殊规范

### 6.1 教程类文档
- 步骤清晰，循序渐进
- 每个步骤都要有验证方法
- 提供完整的代码示例
- 包含常见问题和解决方案

### 6.2 概念解释文档
- 先给出简明定义
- 提供实际应用场景
- 对比相似概念
- 包含优缺点分析

### 6.3 API文档
- 清晰的函数签名
- 参数说明完整
- 返回值描述清楚
- 提供使用示例
